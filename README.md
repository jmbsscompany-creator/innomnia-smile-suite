# Innomnia Smile Suite

We are building INNOMNIA Dental, a premium dental practice management SaaS for small dental clinics in the Dominican Republic.

I want a highly polished, distinctive product — not a generic admin dashboard.

FIRST TASK

Design and implement the visual foundation and the main application shell using fictional demo data.

DESIGN DIRECTION

Premium, elegant, modern healthcare SaaS.

Warm, human, professional, and trustworthy.

Excellent typography, spacing, and visual hierarchy.

Tablet-first responsive design.

A distinctive visual identity for INNOMNIA Dental.

Avoid generic dashboard templates, excessive cards, unnecessary gradients, and meaningless charts.

Prioritize a beautiful daily workspace that a dentist with little digital experience can understand immediately.

BUILD THESE SCREENS

A professional sidebar navigation.

A daily overview screen with:



Today’s appointments.

Pending confirmations.

Quick actions.

A useful appointment timeline.

Patients requiring follow-up.

Today’s collection summary using fictional Dominican pesos (DOP).

A patients page with realistic fictional patient records.

An appointments page with a polished calendar/list layout.

A services and prices page.

IMPORTANT RULES

Use fictional data only.

Do not connect a real database yet.

Do not add authentication yet.

Do not build WhatsApp, AI, payments, or advanced dental charting yet.

Make the navigation functional.

Create reusable components and a consistent design system.

Do not modify any other projects.

Before implementing, briefly explain your design direction and proposed structure. Then build the first version.
